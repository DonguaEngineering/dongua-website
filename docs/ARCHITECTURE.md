## Development Principles

- Mobile-first design
- Semantic HTML
- Accessibility by default
- SEO by default
- Components should remain small and reusable
- Business content must be separated from presentation logic
- English will be used for source code and technical documentation
- No backend or database will be introduced without a concrete requirement
